Portafolio Web

UX/UI con enfoque en QA

Proyecto personal

Demostración práctica de análisis UX, diseño de interfaz y evaluación funcional aplicada a un producto real.

Previsualización de auditoría QA visual y funcional

Objetivo

El objetivo de este portafolio es demostrar competencias en UX, UI y QA mediante un caso práctico que evidencia capacidad de análisis, estructuración de interfaces y optimización de flujos. También muestra habilidades técnicas en HTML, CSS y JavaScript. Está diseñado para que reclutadores, Project Managers y stakeholders puedan revisar el proceso de forma clara, rápida y estructurada.

User Personas

Se definió un User Personas para identificar objetivos, necesidades y puntos de fricción del público meta: reclutadores, Project Managers y stakeholders con tiempo limitado, interesados en evaluar criterio de diseño y proceso de manera eficiente.

Secuencia web

Se desarrolló un diagrama de flujo de navegación para mapear todas las interacciones del sitio, validar la lógica del recorrido, detectar posibles fricciones y asegurar una experiencia clara y coherente.

Wireframes de baja filidedad

Se desarrolló un diagrama de flujo de navegación para mapear todas las interacciones del sitio, validar la lógica del recorrido, detectar posibles fricciones y asegurar una experiencia clara y coherente.

Sistema de diseño

Se establecieron lineamientos de tipografía, color, componentes y espaciado para garantizar consistencia visual, escalabilidad y coherencia en toda la experiencia.

Resultado final

El resultado es un portafolio navegable, estructurado y consistente, que comunica de forma clara el proceso UX/UI/QA y permite evaluar tanto criterio estratégico como capacidades técnicas.

Aprendizajes

Este proyecto reforzó la importancia de definir la experiencia antes del diseño visual y de implementar un Design System desde etapas tempranas. También confirmó que la IA es una herramienta de apoyo que potencia el criterio profesional, pero no sustituye el proceso creativo.
