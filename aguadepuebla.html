Previsualización de auditoría QA visual y funcional

Contraste y accesibilidad visuala

Se identifica el uso de una imagen como fondo, lo que genera un contraste deficiente entre texto y fondo, afectando la legibilidad y la accesibilidad. De acuerdo con las WCAG, el contraste detectado (2.88:1) se encuentra muy por debajo del nivel óptimo (hasta 21:1). A nivel de experiencia, el flujo para añadir contratos introduce complejidad innecesaria, considerando que la mayoría de los usuarios cuenta con un solo contrato. Adicionalmente, el logotipo pierde visibilidad debido a su superposición con el menú tipo hamburguesa. Finalmente, se detecta como hallazgo crítico que el idioma principal de la interfaz sea inglés, pese a estar dirigida a una población mayoritariamente hispanoparlante. Se recomienda establecer el español como idioma por defecto y priorizar el uso de colores sólidos para reducir ruido visual y facilitar la ejecución de tareas.

Sobrecarga de opciones y carga cognitiva

El menú lateral presenta un exceso de opciones, lo que incrementa la carga cognitiva y dificulta la localización de tareas clave. Adicionalmente, el contenido se encuentra únicamente en inglés, lo que no está alineado con el perfil principal de los usuarios. Se identifican elementos de baja relevancia, como web mail, cuya presencia puede generar ruido visual. Se recomienda sintetizar el contenido del menú y mejorar el contraste entre botones y texto, priorizando la usabilidad y la accesibilidad.

Fondo, jerarquía visual y legibilidad

En este caso, se recomienda reemplazar el fondo por un color sólido, actualizar el idioma de la interfaz y reubicar el título del sitio hacia la izquierda, con un margen adecuado que mejore la jerarquía visual. Adicionalmente, es necesario optimizar el contraste entre el título y el fondo para garantizar legibilidad y accesibilidad.

Fricción en el flujo de pago

En este caso, el flujo para pagar una factura de agua resulta tedioso y poco intuitivo, requiriendo aproximadamente cinco pasos para localizar la factura, lo que incrementa la fricción y la carga cognitiva. Adicionalmente, se identifican problemas de contraste entre iconografía y texto, uso de un idioma no alineado con el perfil del usuario, deficiencias en responsividad y una barra de navegación inconsistente. Se recomienda un rediseño integral de la aplicación, enfocado en optimizar el flujo de pago, establecer el idioma correcto y mejorar la intuición, claridad y eficiencia de la experiencia para el usuario.

Comentarios generales y aclaraciones

Este ejercicio no tiene como objetivo desmeritar ni burlarse del trabajo de diseñadores o desarrolladores. Los comentarios presentados forman parte de un ejercicio de QA Visual y Funcional con enfoque en UX, realizado con fines de aprendizaje y portafolio, y buscan aportar retroalimentación constructiva. Como siguiente paso posterior a la auditoría, se planteó un rediseño conceptual apoyado en principios y leyes UX como proximidad, reducción de sobrecarga de opciones y la Ley de Jakob, con el objetivo de mejorar la claridad, la jerarquía visual y la eficiencia de los flujos sin replicar soluciones existentes.
